# quan_ly_atino

Web quản lý cửa hàng thời trang Atino. Mã nguồn trong thư mục `dist/` được lấy từ bản Sites 9 (`700c30c`).

## Chạy thử

```sh
python3 -m http.server 3000 --directory dist
```

Mở [http://localhost:3000](http://localhost:3000) và đăng nhập bằng tài khoản demo đã có. Bản này lưu dữ liệu trong trình duyệt và dùng xác nhận thủ công cho chuyển khoản. Thông tin nhận tiền qua VietQR đã được bỏ khỏi bản GitHub và tên nhân viên trong dữ liệu minh họa đã được thay bằng tên mẫu.
